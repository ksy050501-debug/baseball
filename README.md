# PITCH LAB · ONE INNING

HTML Canvas로 만든 1이닝 투수 야구게임입니다. 플레이어는 투수만 조작하며 상대 타자는 AI가 조작합니다.

## 플레이

저장소의 **Code → Download ZIP**으로 다운로드한 다음 압축을 풀고 `index.html`을 브라우저로 여세요. 별도 설치나 빌드가 필요 없습니다.

이미지까지 포함된 단일 파일을 원하면 `downloads/baseball.html`을 다운로드해 브라우저로 열면 됩니다. 파일을 GitHub 코드 화면에서 보는 것만으로는 게임이 실행되지 않습니다.

## 조작

- **스페이스 두 번 / 투구 버튼 두 번**: 투구 준비 → 중앙에서 릴리스
- **숫자 1~9 / 9칸 클릭**: 목표 코스 선택 (포수 시점, 좌측 상단부터 1~9)
- **타임 · 휴식**: 스태미너 30 회복
- **투구 코칭**: 포인트로 새 구종 습득
- **사운드 ON**: 관중 소리, 투구·포구·타격 효과음

PERFECT는 중앙 ±45ms, GOOD은 ±140ms입니다. 정확한 타이밍에는 구속 상한에 가까운 공과 높은 제구력을 얻으며, MISS에서는 구속과 도착 위치가 흔들립니다.

## 기능

- 9칸 스트라이크 존과 리듬 투구
- 투수 와인드업, 타자 스윙, 포수 포구 애니메이션과 관중석
- 컨택·파워·선구안이 다른 상대 타자 AI
- 포심, 슬라이더, 체인지업, 커브, 스플리터
- 스태미너·구속·구위, 피로와 구종 조합에 따른 타격 판정
- 볼·스트라이크·파울·삼진·볼넷, 안타·장타·홈런
- 주자 진루와 득점, 3아웃 이닝 종료와 이닝 재시작
- 브라우저에 포인트·스태미너·습득 구종 저장

수비는 결과 판정으로 처리합니다. 수비수 이동, 주루 조작, 도루, 더블플레이는 이 버전에 포함되지 않습니다.

## 파일

```text
index.html              경기 화면
style.css               화면 스타일과 모바일 대응
engine.js               투구·타자 AI·카운트·주자·보상 로직
app.js                  입력, Canvas 애니메이션, 사운드, UI 연결
assets/stadium.png      야구장 이미지
assets/players.png      12포즈 선수 스프라이트
assets/prompts.txt      이미지 생성 프롬프트
downloads/baseball.html 이미지와 소스가 포함된 단일 HTML
scripts/pack.cjs        단일 HTML 생성
tests/                  게임 및 UI 연결 로직 검증
```

야구장과 선수 이미지는 OpenAI 내장 imagegen으로 제작했습니다.

## 개발 및 검증

Node.js가 설치된 환경에서 저장소 루트에서 실행합니다. 외부 패키지는 필요 없습니다.

```sh
node tests/game.cjs
node tests/interface.cjs
node scripts/pack.cjs
```

게임 규칙, 코칭과 스태미너 처리, 키보드 타이밍, 애니메이션 완료, 3아웃 후 재시작을 검증하며 랜덤 AI로 100개 이닝도 확인합니다. UI 검증은 모의 DOM/Canvas 환경을 사용하고 실제 브라우저 화면 검증은 별도입니다.
